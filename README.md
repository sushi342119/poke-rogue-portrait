# PokéRogue Portrait（竖屏像素风宝可梦肉鸽对战）

一款专为手机端单手操作设计的 **9:16 竖屏像素风** 宝可梦同人肉鸽（Roguelite）对战游戏。去掉冗长的大地图跑图，聚焦纯粹的回合制策略、双打配合与无尽爬塔构筑。

## 核心特性

- **原生 9:16 竖屏像素舞台**：采用 `270 × 480` 逻辑像素基准分辨率与最近邻采样渲染，保留掌机级锐利像素颗粒感，适配手机单手拇指热区。
- **单打 & 双打双模式**：完整接入全世代战斗计算与状态判定，支持 1v1 单打与 2v2 双打错位站位，内置双打单体技能目标指向选择器（敌左 / 敌右 / 队友）。
- **肉鸽无尽爬塔循环**：波次制推进、随机单/双打遭遇、每 10 层 Boss 战，以及战后底部三选一道具、回复与队伍强化卡牌。
- **第 5 世代像素美术风格**：对接经典黑白（Gen 5）96×96 正背面像素图集与点阵中文字体。

## 技术栈

- **前端与游戏引擎**：Vite + TypeScript + Phaser 3
- **战斗与数据内核**：`@pkmn/sim`（单/双打规则与伤害计算）+ `@pkmn/dex`（全世代图鉴、技能与特性库）
- **移动端封装**：Capacitor（锁定竖屏并导出 Android APK）

## 规划目录结构

```text
poke-rogue-portrait/
├── src/
│   ├── core/
│   │   ├── BattleEngine.ts      # 封装 @pkmn/sim，处理单/双打指令与事件流解析
│   │   └── RogueRunManager.ts   # 肉鸽爬塔层数、遭遇生成与战后三选一状态机
│   ├── scenes/
│   │   └── BattleScene.ts       # 270×480 竖屏像素舞台、精灵站位、血条与受击动画
│   ├── ui/
│   │   └── TouchCommandUI.ts    # 底部拇指触控面板（技能按钮、双打目标选择、三选一卡牌）
│   └── main.ts                  # 游戏入口与像素防模糊配置
├── index.html
├── package.json
└── tsconfig.json
```

## 本地运行与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务器（建议使用浏览器手机竖屏模式预览）
npm run dev

# 构建生产版本
npm run build
```
