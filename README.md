# PokéRogue Portrait（竖屏像素风宝可梦对战 & 无尽肉鸽）

一款专为手机端单手操作设计的 **9:16 竖屏像素风** 宝可梦同人策略对战与肉鸽（Roguelite）游戏。支持连接大模型 AI 进行高强度单/双打正统博弈，并提供快节奏的无尽单打爬塔玩法，配备完整的第 5 世代动态精灵、像素技能特效与原版音效。

## 核心特性

- **正统对战模式（Lv.50 单打 3v3 / 双打 4v4）**：包含**自由编队**与**随机池挑选组队（对战工厂）**两种子模式，单局快速结算。
- **AI 战术对抗（思考摘要 + 台词气泡）**：支持接入外部大模型 API 或使用本地启发式 AI，实时展示战术思考摘要与训练家台词气泡。
- **肉鸽无尽模式（独立 1v1 单打）**：随机三选一开局、野生收服扩编、每 5 层精英 / 10 层 Boss、战后底部三选一卡牌构筑。
- **全套像素视听体验**：全世代黑白动态精灵（Animated Sprites）、18 属性像素技能打击特效、官方宝可梦原版叫声（Cries）与掌机风多场景战斗 BGM。

## 技术栈

- **前端与渲染引擎**：Vite + TypeScript + Phaser 3（`270 × 480` 竖屏像素防模糊）
- **战斗与数据内核**：`@pkmn/sim` + `@pkmn/dex`
- **音频与特效系统**：Web Audio API 8-bit 合成器 + Showdown 动态精灵/音效图床 + 本地离线资源同步脚本
- **移动端打包**：Capacitor（锁定竖屏 Android APK）

## 本地运行与构建

```bash
npm install
npm run dev
npm run build
```
