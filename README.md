# PokéRogue Portrait（竖屏单手像素宝可梦肉鸽刷塔）

一款专为手机端单手操作设计的 **9:16 竖屏像素风** 纯正宝可梦肉鸽刷塔（PokéRogue-like）游戏。兼具 **Pokémon Showdown** 的高信息密度战术操控手感（同屏 4 招克制倍率 + 6 槽秒换 + 点击侦察速度线）与 **PokéRogue** 的深度局内外刷塔构筑闭环。

## 核心玩法特性

- **双爬塔模式并存**：
  - **经典爬塔模式（200 层）**：10 费初始编队、固定波次宿敌 6 阶进化拦路（8/25/55/95/145/195 层）、8 大群系驻守道馆主、第 182~190 层四天王冠军连战与第 200 层 5 段护盾终焉霸主 **无极汰那** 决战，通关授予殿堂缎带与黄金十连蛋券。
  - **无尽刷塔模式（∞ 层）**：15 费高自由度神兽/多闪光开局、初始自带闪光护符、黄金诱饵触发 **野生 2v2 双打刷闪/刷经验**、圣物无限叠层冲榜。
- **蛋券扭蛋机 & 孵蛋工坊**：击败道馆主、宿敌与里程碑 Boss 掉落普通/精良五连/黄金十连蛋券；提供 **招式 UP / 传说 UP / 闪光 UP** 三大扭蛋机，破壳解锁新初始宠、异色闪光形态与 4 槽超模遗传蛋招式（Egg Moves）。
- **初始宠糖果潜能养成**：收服、主力闯关与孵蛋积累专属糖果，可永久 **降低初始出战费用（-1/-2 费）**、**觉醒 6V 满个体与战后再生被动**，或定向兑换高闪光专属彩蛋。
- **10 层群系择路与锁品质双轨商店**：每 10 波关底通关选择下一章节生态群系路线（拾取【城镇地图】解锁 3 分支与道馆情报）；战后双轨商店支持常驻金币补给、3 张精灵球品质免费战利品三选一与【锁定胶囊】锁品质刷新。
- **双栈战术 AI 与全世代像素视听**：宿敌与道馆主支持接入外部 OpenAI 兼容大模型（严格遵守战争迷雾 + 超时无缝回退本地战术 AI）；配备 1,025 全世代简中图鉴、第 5 世代动态像素精灵、18 属性打击特效与原版叫声/BGM。
